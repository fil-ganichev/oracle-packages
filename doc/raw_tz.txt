Есть спецификации 3-х встроенных Oracle пакетов - standard, utl_raw, utl_encode.
Необходимо создать из Java-реализацию
Для получения информации о функциональности конкретных методов пакетов (что они должны делать) нужно найти в интернет документацию Oracle
Если метод пакета ссылается на другой пакет, нужно сделать заглушку вызова
Типы данных должны быть врапперные:

Общий тип Var, наследники Varchar2Var, NumberVar и другие. В них должны быть методы isNull, get, set
Для default-параметров использовать параметры Optional
Перегруженные методы именовать так:

someMethod
someMethod$1
someMethod$2

Делай комментарии в коде на кириллице

Для реализации создай пакет в папке oracle-packages

Спецификации пакетов лежат в oracle-packages/sql
